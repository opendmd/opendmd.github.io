Third-party licences: the OpenDMD firmware
==========================================

OpenDMD is MIT OR Apache-2.0 (LICENSE-MIT, LICENSE-APACHE). The firmware the
installer writes - the firmware itself, its bootloader and the updater - is
built with the open-source software below, each used under the licence named;
the full texts follow, numbered. The web app the player serves has its own
list (THIRD-PARTY-LICENSES-web.txt). Generated from the release build by
tools/notices.py.

Components
----------

ESP-IDF 5.3.0: Apache-2.0 [1]
  https://github.com/espressif/esp-idf
  Espressif's IoT Development Framework: the startup code, drivers, FreeRTOS
  port, heap, flash, NVS, SD card, FAT, networking, HTTP server and TLS glue,
  the second-stage bootloader, and Espressif's Wi-Fi, PHY and coexistence
  libraries, which Espressif distributes in object form only under the same
  Apache-2.0 licence (components/esp_wifi/lib/README.rst).
  In: firmware, bootloader, updater.

FreeRTOS kernel 10.5.1: MIT [2]
  https://github.com/espressif/esp-idf/tree/master/components/freertos
  Amazon's FreeRTOS kernel, with Espressif's SMP changes.
  In: firmware, updater.

lwIP 2.1.3: BSD-3-Clause [3]
  https://savannah.nongnu.org/projects/lwip/
  In: firmware.

Mbed TLS 3.6.0: Apache-2.0 [1]
  https://github.com/Mbed-TLS/mbedtls
  Dual-licensed Apache-2.0 OR GPL-2.0-or-later; used here under Apache-2.0.
  In: firmware.

wpa_supplicant: BSD-3-Clause [4]
  https://w1.fi/wpa_supplicant/
  In: firmware.

fastpbkdf2: CC0-1.0
  https://github.com/ctz/fastpbkdf2
  Joseph Birr-Pixton's fast PBKDF2 (wpa_supplicant's
  esp_supplicant/src/crypto/fastpbkdf2.c), dedicated to the public domain
  under CC0 1.0.
  In: firmware.

TLSF allocator: BSD-3-Clause [5]
  https://github.com/espressif/tlsf
  Matthew Conte's Two-Level Segregated Fit allocator (the text from upstream's
  tlsf.h at mattconte/tlsf deff9ab).
  In: firmware, updater.

FatFs R0.15: the FatFs licence (BSD-style, one clause) [6]
  http://elm-chan.org/fsw/ff/
  In: firmware, updater.

SD/MMC protocol driver (from OpenBSD): ISC [7]
  https://github.com/openbsd/src/tree/master/sys/dev/sdmmc
  In: firmware, updater.

UBSAN runtime (from HelenOS): BSD-2-Clause [8]
  In: firmware, updater.

http-parser 2.7.0: MIT [9]
  https://github.com/nodejs/http-parser
  In: firmware.

Xtensa RTOS port (Cadence): MIT [10]
  In: firmware, updater.

  The C library's functions linked in (stdio, strings, time, locale) are under

GCC runtime libraries (libstdc++, libgcc): GPL-3.0-or-later WITH GCC-exception-3.1 [13]

  Linked from Espressif's GCC toolchain for the C++ HUB75 driver. The GCC

  In: firmware.

ESP-IDF mDNS component (espressif/mdns) 1.2.5: Apache-2.0 [1]

  In: firmware.

ESP32-HUB75-MatrixPanel-DMA 3.0.14: MIT [14]

LovyanGFX (the HUB75 driver's I2S DMA code): BSD-2-Clause [15]

  In: firmware.

Silkscreen (the setup page's heading font, a subset): OFL-1.1 [16]
