# The OpenDMD formula gallery

Formulas for the [OpenDMD](https://opendmd.dev/) LED display, contributed
by pull request: see [gallery/README.md](gallery/README.md). The gallery
is shown at [opendmd.dev/formulas](https://opendmd.dev/formulas/).

`.github/`, this file, `gallery/README.md` and `dev/api/` (the HTTP API
page as each release described it) are written by OpenDMD's
`make gallery-repo-publish`; a change made to them here is replaced by the
next one. Only `gallery/` takes contributions.
