# opendmd.github.io

The OpenDMD site: documentation and a browser demo of the web app (https://opendmd.github.io/). Built by `make site` in the OpenDMD repository; changes made here are overwritten by the next publish, except in `gallery/`: the formula gallery, which takes contributions by pull request (see gallery/README.md), and `dev/api/`: the HTTP API page as each release described it, kept from one publish to the next.
